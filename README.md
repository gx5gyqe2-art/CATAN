# カタン盤面メーカー

カタンの初期盤面（地形タイル・数字チップ・港）をランダムに生成し、プロジェクターで全画面投影するためのページです。

## 使い方

`index.html` をブラウザで開くか、GitHub Pages の公開URLにアクセスしてください。

| キー | 操作 |
| --- | --- |
| Space | 新しい盤面を作る |
| Z | ひとつ前の盤面に戻す |
| M | 3〜4人用 / 5〜6人用を切り替える |
| F | 投影モード（全画面）の開始・終了 |
| Esc | 投影モードを終了 |

## できること

- 3〜4人用（地形19枚・数字チップ18枚・港9つ）と5〜6人拡張（地形30枚・数字チップ28枚・港11）
- 並べ方のルール：6と8を隣り合わせない / 同じ数字を隣り合わせない / 同じ地形を隣り合わせない
- 資源ごとの産出力（サイコロ36回あたりの当たり回数の目安）を表示
- タイルを実物の写真で表示（イラスト表示にも切り替え可）

港は位置を固定し、種類だけをランダムに入れ替えています。位置は公式の枠と完全には一致しない場合があります。

外部依存はなく、1ファイルで動作します（Google Fonts が読み込めない環境では標準フォントで表示されます）。

## 指差し操作（開発中・`feature/finger-control` ブランチ）

壁に投影した盤面を指で差して、開拓地・都市を置く／動かすための仕組みです。資源カードなどは実物を使う前提で、盤面上の駒だけを扱います。

### 構成

| 役割 | ファイル | 置き場所 |
| --- | --- | --- |
| 投影用スマホ（プロジェクターにつなぐ） | `play.html` | GitHub Pages |
| カメラ用スマホ（後ろから壁を撮る） | `cam.html` | GitHub Pages |
| 中継サーバー（2台をつなぐ） | `worker/` | Cloudflare Workers |

カメラ用スマホはブラウザだけで手の骨格を検出し（MediaPipe Hands）、人差し指の先の位置と「親指と人差し指をつまんでいるか」を中継サーバー経由で投影用スマホに送ります。映像そのものは送りません。

### 中継サーバーのデプロイ（最初に1回）

```bash
cd worker
npm install
npx wrangler login      # ブラウザで Cloudflare にログイン
npx wrangler deploy     # 終わると https://catan-relay.xxxx.workers.dev が表示される
```

表示された URL を `https://` → `wss://` に変えて `config.js` の `CATAN_RELAY` に入れ、push します。無料プランで動きます（Durable Objects の SQLite 版を使用）。

### 使い方

1. **投影用スマホ**で `play.html` を開き、プロジェクターに映します。「全画面」を押し、画面上部の**ルームコード**を控えます。四隅に白い目印が出ます。
2. **カメラ用スマホ**で `cam.html` を開き、中継サーバーのアドレスとルームコードを入れて「接続」。「カメラを開始」を押します。
3. カメラ用スマホを、投影面全体が映る位置（プレイヤーの後ろ、少し高め）に固定します。
4. 「位置合わせ」を押し、映像の中の目印を **左上 → 右上 → 右下 → 左下** の順にタップします。これでカメラの座標と盤面の座標が対応します。
5. 壁を指差すと、投影画面に指先のカーソルが出ます。
   - **つまむ（親指と人差し指）** … つかむ。空いている頂点なら、今の色の開拓地を持ち上げる
   - **つまんだまま動かして離す** … 一番近い頂点に置く（隣の頂点に駒があると置けません）
   - **同じ場所でつまんで離す** … 開拓地 ⇄ 都市を切り替える
   - **盤面の外で離す** … 駒を外す
   - **左の色の丸をつまむ** … 手番の色を切り替える
6. 投影用スマホの画面を直接タッチしても同じ操作ができます（カメラが不調なときの予備）。

### うまくいかないとき

- 手が検出されない … 手に強い投影光が当たっていると落ちます。カメラを少し横にずらすか、「調整」で「つまみ判定のしきい値」を上げてみてください。
- カーソルがずれる … カメラやプロジェクターを動かしたら「位置合わせ」をやり直してください。
- つまみが反応しすぎる／しない … 「調整」のしきい値を変えます。小さいほど強くつままないと反応しません。
